# CDS 预览运行约定

前端在 CI 构建时使用 `VITE_API_BASE_URL=front`，由预览 Nginx 剥离
`/front/` 后代理到当前分支后端。容器启动时设置 Vite 变量不会改变已构建资源。

后端必须从 CDS 本分支变量读取 `MS_WECOM_SECRET_MASTER_KEY`。在部署前通过
CDS 本分支私有变量编辑器生成并保存随机值，不复制生产密钥，不写入 Git、镜像、
报告或日志。入口缺少该值时停止，避免容器重建后更换加密身份。

该变量随分支配置保留，独立数据库与密钥必须配套备份和恢复。删除分支配置前，
必须通过受控凭据备份流程保留密钥；仅保留数据库不能恢复已加密配置。本次不删除
分支、数据库或密钥，也不把密钥写入构建产物。恢复验证应使用合成数据，确认
容器重建前后仍能使用原加密配置；配置已保存不等于该验证已通过。

数据库使用本分支 `per-branch` 覆盖，启动前核对目标库和账户权限，禁止回退为
共享库以绕过初始化问题。Redis、Kafka、MinIO 的实例与命名空间须另外验证，
不能用 MySQL 的独立库配置声明全部基础设施已隔离。
